# Thumbnail Rules

블로그 썸네일은 작은 카드에서도 주제를 즉시 인식할 수 있는 동일한 시각 언어를 사용한다.

## 파일 규칙

- 저장 위치: `public/thumnail/{type}/{id}.webp`
- 프로젝트: `public/thumnail/projects/{id}.webp`
- Devlog: `public/thumnail/devlog/{category}/{id}.webp`
- 포맷: WebP
- 크기: `576 × 384px` (3:2)
- 파일명: 콘텐츠의 하이픈 없는 Notion ID와 정확히 일치
- 알파 채널 없이 RGB/YUV 이미지로 저장

## 시각 규칙

- 배경은 흰색 또는 아주 옅은 청색의 정사각 격자 패턴을 사용한다.
- 주요 색상은 네이비, 슬레이트, 코발트 블루와 흰색으로 제한한다.
- 주제 하나를 중앙에 배치한 단일 아이소메트릭/플랫 3D 일러스트로 구성한다.
- 콘텐츠 주제를 나타내는 핵심 오브젝트는 화면 중앙 60~75% 영역에 두고 가장자리 여백을 확보한다.
- 텍스트, 로고, 워터마크, 브랜드 고유 UI, 작은 판독 불가능한 문구는 넣지 않는다.
- 그림자와 입체감은 보조적으로 사용하되, 어두운 풀블리드 배경이나 사진 스타일은 피한다.
- 카드의 작은 크기에서도 실루엣과 주제 구분이 유지되어야 한다.

## 주제별 방향

- 프로젝트: 서버, 애플리케이션, 데이터 흐름, 시스템 구성처럼 결과물을 상징하는 오브젝트
- Devlog: 글의 기술 주제를 상징하는 도구, 구조, 흐름 또는 문제/해결 대비
- Journal: 학습·기록 주제를 단순화한 교육용 오브젝트

## 검수 체크리스트

1. 파일이 올바른 ID 경로에 있는가?
2. 이미지가 WebP이며 576×384px인가?
3. 밝은 격자 배경과 네이비/블루 팔레트를 지키는가?
4. 중앙 단일 주제가 작은 크기에서도 식별되는가?
5. 텍스트·로고·워터마크·과도한 장식이 없는가?
6. `npm run validate:content`와 관련 브라우저 테스트가 통과하는가?
