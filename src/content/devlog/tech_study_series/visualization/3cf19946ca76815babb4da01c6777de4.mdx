## 핵심 요약

데이터 위에 의미를 얹는 도구는 **`ax.annotate`(화살표가 있는 주석)**, **`ax.text`(단순 텍스트)**, 그리고 **`axhline`/`axvline`/`axhspan`/`axvspan`(기준선·기준 구간)**입니다.
텍스트 위치는 **좌표계(데이터 좌표 vs Axes 비율 좌표)**를 무엇으로 잡느냐가 핵심이며, `transform` 인자로 지정합니다.
수식은 달러 기호로 감싼 **mathtext**로 쓰고, 한글은 **폰트 설정(`font.family`)과 `axes.unicode_minus=False`**를 지정하지 않으면 깨지거나 마이너스 기호가 사라집니다.


```python
import matplotlib.pyplot as plt
import numpy as np
```

## 1. `ax.annotate` -화살표 주석

특정 데이터 지점을 가리키며 설명을 답니다.


```python
x = np.linspace(0, 10, 100)
y = np.sin(x)
fig, ax = plt.subplots()
ax.plot(x, y)

peak = x[np.argmax(y)]
ax.annotate(
    "first peak",
    xy=(peak, 1.0),                       # 가리킬 지점 (데이터 좌표)
    xytext=(peak + 1.5, 0.5),             # 글자 위치 (데이터 좌표)
    arrowprops=dict(arrowstyle="->", color="gray"),
    fontsize=10,
)
```

- `xy`는 화살표 끝(가리키는 곳), `xytext`는 글자가 놓이는 곳입니다.
- `xycoords`/`textcoords`로 좌표계를 바꿉니다. 기본은 `"data"`(데이터 좌표), `"axes fraction"`은 Axes 기준 0~1 비율.
- `arrowprops` 없이 쓰면 화살표 없는 텍스트가 됩니다.
> 💡 **이럴 때**: "이 그림에서 봐야 할 곳"이 분명하면 제목에 결론을 쓰고(`ax.set_title("Q3에 매출이 정점")`) 해당 지점에 `annotate`로 화살표를 답니다. 독자가 스스로 찾게 두지 않습니다. → 데이터 전처리·시각화 이론 학습 로드맵 2.11

## 2. `ax.text` -좌표계와 transform


```python
ax.text(0.5, 5, "data-space label")                       # 데이터 좌표
ax.text(0.02, 0.95, "top-left corner", transform=ax.transAxes,
        va="top", ha="left")                              # Axes 비율 좌표
```


<NotionTable>
  <tbody>
    <tr><td>`transform`</td><td>의미</td><td>용도</td></tr>
    <tr><td>`ax.transData`(기본)</td><td>x, y가 데이터 값</td><td>특정 관측치 옆 라벨</td></tr>
    <tr><td>`ax.transAxes`</td><td>x, y가 0~1 (Axes 좌하단 0,0 ~ 우상단 1,1)</td><td>패널 이름("A"), 통계 요약 박스</td></tr>
    <tr><td>`fig.transFigure`</td><td>Figure 전체 기준 0~1</td><td>그림 전체 각주</td></tr>
  </tbody>
</NotionTable>

- `ha`(가로 정렬: left/center/right), `va`(세로 정렬: top/center/bottom)로 기준점을 잡습니다.
- 배경 박스: `bbox=dict(boxstyle="round", fc="white", ec="gray", alpha=0.8)`.

## 3. 기준선·기준 구간


```python
ax.axhline(y=0, color="black", linewidth=0.8)          # 수평선 (y=0 기준선)
ax.axvline(x=pd_launch_date, color="C3", linestyle="--", label="출시일")
ax.axhspan(90, 100, color="green", alpha=0.1)          # 수평 띠 (목표 구간)
ax.axvspan("2026-03", "2026-05", color="gray", alpha=0.15)  # 수직 띠 (특정 기간)
```

- `axhline`/`axvline`은 축 전체를 가로지르는 선, `axhspan`/`axvspan`은 범위를 채운 띠입니다.
- 좌표 지정 없이 축 끝까지 자동으로 뻗습니다(부분만 원하면 `xmin`/`xmax`를 0~1 비율로).
> 💡 **이럴 때**: 임계치(SLA 99%, 손익분기점)나 사건 발생 시점(배포, 정책 변경)을 `axhline`/`axvline`으로 표시하면 데이터가 그 기준을 넘었는지 즉시 읽힙니다.

<a id="4-수식-mathtext"></a>

## 4. 수식 -mathtext


```python
ax.set_xlabel(r"$\lambda$ (wavelength, nm)")
ax.set_title(r"$E = mc^2$,  $\sum_{i=1}^{n} x_i$")
ax.text(0.5, 0.5, r"$\bar{x} \pm \sigma$", transform=ax.transAxes)
```

- 달러 기호 `$...$` 안이 수식으로 렌더링됩니다. 문자열 앞에 `r`(raw string)을 붙여 백슬래시가 이스케이프되지 않게 합니다.
- 별도 LaTeX 설치 없이 matplotlib 내장 mathtext가 처리합니다. 완전한 LaTeX가 필요하면 `text.usetex=True`(시스템에 LaTeX 필요).

<a id="5-한글-폰트-설정-이슈"></a>

## 5. 한글 폰트 설정 이슈

논의 계층을 분리합니다. 한글 깨짐은 **① 폰트 지정 문제**와 **② 마이너스 기호 문제**가 별개로 겹칩니다.


```python
import matplotlib.pyplot as plt

# ① 한글 폰트 지정 (설치된 폰트 이름을 사용)
plt.rcParams["font.family"] = "Malgun Gothic"   # Windows
# plt.rcParams["font.family"] = "AppleGothic"   # macOS
# plt.rcParams["font.family"] = "NanumGothic"   # Linux (나눔폰트 설치 후)

# ② 유니코드 마이너스(−)를 ASCII 하이픈(-)으로 → 축의 음수가 □로 깨지는 것 방지
plt.rcParams["axes.unicode_minus"] = False
```

- 기본 폰트(DejaVu Sans)에는 한글 글리프가 없어 한글이 모두 두부(□)로 나옵니다.
- 폰트를 바꿔도 새 폰트를 설치한 직후에는 캐시 때문에 반영이 안 될 수 있습니다. `matplotlib.font_manager._load_fontmanager(try_read_cache=False)` 또는 캐시 파일 삭제 후 재시작.
- 설치된 폰트 이름 확인:

```python
from matplotlib import font_manager
[f.name for f in font_manager.fontManager.ttflist if "Gothic" in f.name or "Nanum" in f.name]
```

- 특정 텍스트에만 폰트를 주려면 `ax.set_title("제목", fontproperties=font_manager.FontProperties(fname="C:/Windows/Fonts/malgun.ttf"))`.
> 💡 **이럴 때**: 축 라벨의 한글은 나오는데 음수 눈금이 `□2`, `□4`로 보이면 폰트가 아니라 `axes.unicode_minus` 문제입니다. `False`로 지정합니다.

💡 **이럴 때**: 협업 환경(CI, 동료 PC)에서 폰트 이름이 제각각이면, 폰트 파일을 리포지토리에 포함하고 `font_manager.fontManager.addfont(path)` 후 `font.family`에 그 폰트 이름을 지정해 환경 독립적으로 만듭니다.
