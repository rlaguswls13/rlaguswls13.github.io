## **핵심 요약**

파이썬(Python)은 문법이 간결하고 가독성이 뛰어난 **인터프리터 방식의 동적 타이핑(Dynamic Typing) 고급 프로그래밍 언어**다. 코드 블록을 중괄호(`{}`) 대신 **들여쓰기(Indentation)**로 구분한다.


<NotionDivider />

<a id="1-변수와-동적-타이핑-dynamic-typing"></a>

## **1. 변수와 동적 타이핑 (Dynamic Typing)**

파이썬에서는 변수의 타입을 명시적으로 선언하지 않으며, **대입되는 객체(Object)에 따라 변수의 타입이 동적으로 결정**된다.


```python
# 변수 선언 및 타입 동적 결정
age = 25          # int
gpa = 3.8         # float
name = "Alice"    # str
is_active = True  # bool

# 파이썬의 모든 것은 객체(Object)다.
# id() 함수로 객체의 메모리 주소를 확인할 수 있다.
print(type(name)) # <class 'str'>
print(id(name))   # 객체 메모리 주소 출력
```

## **2. 주요 연산자**

- **산술 연산자**: `+`, `-`,`*` , `/` (실수 나눗셈), `//` (정수 몫), `%` (나머지), `**` (거듭제곱)
- **비교 연산자**: `==`, `!=`, `>`, `<`, `>=`, `<=`
- **논리 연산자**: `and`, `or`, `not`
- **멤버십 연산자**: `in`, `not in` (리스트, 튜플, 문자열 내부 포함 여부 확인)

```python
# 멤버십 연산자 예시
fruits = ["apple", "banana", "cherry"]
print("banana" in fruits)  # True
```

## **3. 제어문 (Control Flow)**

<a id="1-조건문-if-elif-else"></a>

### **① 조건문 (****`if - elif - else`****)**


```python
score=85
if score>=90:
	print("A 학점")
elif score>=80:
	print("B 학점")# 실행됨
else:
	print("C 학점")
```

<a id="2-반복문-for-while"></a>

### **② 반복문 (****`for`****,** **`while`****)**


```python
# for 문과 range()
for i in range(1, 6): # 1부터 5까지 반복
    print(f"Count: {i}")

# range() 응용: range(start, stop, step)
for odd in range(1, 10, 2): # 1, 3, 5, 7, 9
    print(odd)

# while 문과 break / continue
count = 0
while count < 5:
    count += 1
    if count == 3:
        continue # 3일 때 건너뜀
    print(count)
```

## **4. 들여쓰기(Indentation)와 코드 블록 (Java** **`{}`****와의 차이점)**

파이썬은 Java나 C 계열 언어와 달리 중괄호(`{}`)로 코드 블록(Block Scope)을 나누지 않는다.

대신 **콜론(`:`)과 들여쓰기(Indentation)**를 사용하여 코드의 제어 범위와 블록 구획을 나눈다.


```python
[Java 방식: 중괄호 블록]
if (score >= 90) {
    System.out.println("Pass"); // 들여쓰기는 단순 가독성용
}
[Python 방식: 콜론 + 들여쓰기 블록]
if score >= 90:
    print("Pass") # 들여쓰기 필수! 들여쓰기 단계가 곧 코드의 포함 관계(Scope)임
```

<a id="5-파이썬-들여쓰기-작성-수칙-pep-8-표준"></a>

## **5. 파이썬 들여쓰기 작성 수칙 (PEP 8 표준)**

1. **공백(Space) 4칸 권장 (PEP 8 표준)**:
- 파이썬 공식 스타일 가이드(PEP 8)에서는 코드 블록 1단계당 **스페이스 4칸(4 Spaces)** 사용을 표준으로 정의한다.

1. **Tab과 Space 혼용 금지**:
- 탭(Tab)과 스페이스(Space)를 같은 파일 안에서 혼용하면 **`TabError`*가 발생한다. 대부분의 현대 IDE(VS Code, PyCharm)는 Tab 키를 누르면 자동으로 공백 4칸으로 변환해 준다.

1. **빈 블록 처리 키워드 (****`pass`****)**:
- 콜론(`:`) 뒤에 구문상 들여써야 하지만 아직 구현할 내용이 없는 경우 **`pass`** 키워드를 써서 에러를 방지한다.


```python
# 들여쓰기 작성 예시
def process_data(data):
    if not data:
        pass  # 추후 구현 예정 (IndentationError 방지)
    else:
        for item in data:
            print(item)  # 2단계 들여쓰기 (공백 8칸)
```

## **6. 자주 발생하는 들여쓰기 에러 (Troubleshooting)**

- **`IndentationError: expected an indented block`**:
- `if`, `for`, `def`, `class` 등 콜론(`:`)이 나온 다음 줄에 들여쓰기가 누락되었을 때 발생.

- **`IndentationError: unexpected indent`**:
- 들여쓰지 말아야 할 위치에 불필요한 공백이 들어갔을 때 발생.

- **`TabError: inconsistent use of tabs and spaces in indentation`**:
- 탭 문자(Tab)와 공백(Space)이 섞여서 사용되었을 때 발생.
