## 핵심 요약

파이썬은 <strong>4대 빌트인 자료구조(List, Tuple, Set, Dictionary)</strong>를 기본 제공하며, <strong>컴프리헨션(Comprehension)</strong>을 통해 파이썬다운(Pythonic) 코드를 작성할 수 있다.

## 2. 컴프리헨션 (Comprehension)

반복문과 조건문을 축약하여 새로운 리스트나 딕셔너리를 한 줄로 생성하는 기능이다.


```python
# 1. List Comprehension (짝수 제곱 리스트 생성)
evens_squared=[x**2 for x in range(10) if x%2==0]
# 결과: [0, 4, 16, 36, 64]
# 2. Dictionary Comprehension (이름: 글자수 매핑)
names=["Alice","Bob","Charlie"]
name_len_map={name:len(name) for name in names}
# 결과: {'Alice': 5, 'Bob': 3, 'Charlie': 7}
```

## <strong>3. 파이썬 함수 (Function) 및 1급 객체 (First-Class Citizen)</strong>

<a id="1-기본-정의-및-가변-인자-args-kwargs"></a>

### 1) 기본 정의 및 가변 인자 (`*args`, `**kwargs`)


```python
def calculate_total(base_price, *args, **kwargs):
    """
    *args: 위치 가변 인자 (Tuple 형태로 수신)
    **kwargs: 키워드 가변 인자 (Dict 형태로 수신)
    """
    total = base_price + sum(args)
    discount = kwargs.get("discount", 0)
    return total - discount

print(calculate_total(100, 10, 20, discount=15)) # 100 + 30 - 15 = 115
```

<a id="2-1급-객체first-class-citizen로서의-함수-lambda"></a>

### 2) 1급 객체(First-Class Citizen)로서의 함수 & Lambda

파이썬에서 함수는 <strong>변수에 할당할 수 있고, 다른 함수의 인자로 전달되거나 반환값으로 사용</strong>될 수 있다.


```python
# Lambda 익명 함수 및 함수 인자 전달
numbers = [5, 2, 8, 1, 9]
sorted_numbers = sorted(numbers, key=lambda x: -x) # 내림차순 정렬
```
