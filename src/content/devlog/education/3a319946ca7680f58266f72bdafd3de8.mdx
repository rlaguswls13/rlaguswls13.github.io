## **1. Spring Framework란?**

Spring Framework는 자바 엔터프라이즈 애플리케이션 개발을 편하게 해주는 거대한 오픈소스 애플리케이션 프레임워크입니다. 개발자가 복잡한 '객체 생성과 생명주기 관리(IoC/DI)'나 '트랜잭션 처리' 같은 인프라적인 고민을 덜고, 핵심 비즈니스 로직을 짜는 데 집중할 수 있도록 돕는 뼈대 역할을 합니다.

<a id="1-spring-boot-vs-spring"></a>

### **1) Spring Boot vs Spring**

이 둘의 관계는 '부품과 조립품'으로 이해하면 쉽습니다.


<NotionIndent>

• **Spring Framework (부품 창고):** 웹 개발에 필요한 모든 기능(보안, DB 연결, 뷰 렌더링 등)을 제공하지만, 개발자가 일일이 버전을 맞추고 복잡한 설정 파일(XML 또는 Java Config)을 작성한 뒤 톰캣(Tomcat) 같은 외부 웹 서버에 올려야 했습니다.
• **Spring Boot (완성된 자동차):** Spring Framework를 기반으로 하되, "복잡한 설정은 우리가 미리 다 해둘 테니 너는 바로 코딩만 시작해!"라는 철학으로 만들어졌습니다. 설정이 자동화되어 있고 웹 서버가 내장되어 있어 실행 버튼 하나만 누르면 바로 웹 서버가 켜집니다. 


</NotionIndent>

<a id="2-spring-boot가-개발된-이유"></a>

### **2) Spring Boot가 개발된 이유?**

(1) **초기 설정의 복잡성 해결 (설정 지옥 탈출):** 기존 Spring은 프로젝트 세팅에만 며칠이 걸리기도 했습니다. Spring Boot는 '관례(Convention)'를 따르는 자동 설정(Auto-configuration)을 도입해 이 과정을 획기적으로 줄였습니다.

(2) **독립 실행형(Standalone) 애플리케이션:** 외부 WAS(웹 서버)를 별도로 설치하고 배포하는 과정 없이, 내장형 톰캣(Tomcat) 등을 활용해 스스로 실행 가능한 JAR 파일 하나만 뚝딱 만들어 냅니다.

(3) **마이크로서비스 아키텍처(MSA) 대응:** 서비스를 작게 여러 개 쪼개서 운영하는 클라우드 환경에서는 앱을 빠르고 가볍게 띄워야 합니다. 빠르고 독립적인 실행이 가능한 Spring Boot는 MSA에 완벽하게 부합했습니다.

## **3. Spring Boot 이외에 지원되는 유용한 Spring projects**  

Spring 생태계([https://spring.io/projects)에는](https://spring.io/projects)에는) 웹 개발의 특정 영역을 담당하는 훌륭한 자식 프로젝트들이 많습니다.

• **Spring Data:** JDBC, JPA, MongoDB, Redis 등 다양한 데이터베이스 접근 기술을 일관된 인터페이스로 묶어줍니다. 개발자가 SQL을 직접 짜지 않아도 메서드 이름만 규칙에 맞게 적으면 알아서 쿼리를 만들어주는 마법 같은 기능을 제공합니다 (Spring Data JPA).

• **Spring Security:** 애플리케이션의 든든한 경비원입니다. 비밀번호 암호화, 로그인 인증, 권한 관리, 세션 공격 방어, OAuth2 (소셜 로그인) 등을 강력하게 지원합니다.

• **Spring Cloud:** 넷플릭스나 배달의민족처럼 서버가 수십~수백 대인 분산 시스템(MSA)을 구축할 때 필요합니다. 서버끼리 서로를 찾게 해 주거나(Service Discovery), 트래픽을 분산시키고, 한 서버가 죽었을 때 다른 서버로 우회시키는 등 클라우드 네이티브 환경을 위한 도구 모음입니다.

• **Spring Batch:** 매일 자정에 수백만 건의 결제 내역을 정산해야 한다면? 이렇게 대용량 데이터를 일괄적으로 끊어서 처리하고, 중간에 실패하면 그 지점부터 다시 시작하게 해주는 배치 전용 프레임워크입니다.

• **Spring AI:** 최근 가장 각광받는 프로젝트로, OpenAI, Hugging Face 등 다양한 AI 모델과 프롬프트 엔지니어링을 Spring 백엔드에 쉽게 연동할 수 있게 해줍니다.

## **4. 이런 Spring projects는 어떻게 활용(배우나요)?**

<a id="1-활용-방법-실무"></a>

### 1)  **활용 방법 (실무)**

Spring Boot의 의존성 관리 도구(`pom.xml` 또는 `build.gradle`)에 **'Starter' 라이브러리 한 줄만 추가**하면 끝납니다.

    ◦ *예:* DB 연동이 필요하면 `spring-boot-starter-data-jpa`, 보안이 필요하면 `spring-boot-starter-security`를 추가하면 Spring Boot가 알아서 모든 설정을 조립해 줍니다.  

<a id="2-추천-학습-과정"></a>

### 2) **추천 학습 과정**

(1) **Spring Initializr (start.spring.io)**
웹 브라우저에서 사용할 프로젝트(Security, Web, Data JPA)를 체크박스로 선택하여 기본 뼈대를 생성합니다. 실무에서도 이 방식으로 프로젝트를 시작합니다. 

(2) **공식 가이드 따라 하기 (spring.io/guides)**
각 기술별로 15분 분량의 "Building a RESTful Web Service", "Securing a Web Application" 같은 튜토리얼을 그대로 타이핑하며 감을 잡습니다.
